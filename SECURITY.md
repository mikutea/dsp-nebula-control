# Security policy

Please do not open a public issue containing credentials, Steam state, real
server endpoints, player information, saves, logs, configuration exports, or
unredacted screenshots.

For security vulnerabilities, use a private GitHub security advisory for this
repository. Include the affected version, reproduction steps, impact, and any
suggested mitigation. Do not test a report against infrastructure you do not
own or have permission to assess.

The current `0.1.x` foundation intentionally leaves every game/server mutation
disabled. See [docs/SECURITY.md](docs/SECURITY.md) for trust boundaries and
security invariants.
